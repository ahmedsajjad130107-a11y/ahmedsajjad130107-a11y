### 📐 CAD AI
**Photo-to-2D CAD prototype**

An experimental tool exploring how image processing can extract a flat part's outline and inner holes, then turn those contours into a scale-aware 2D drawing workflow.

**What it explores**
- Image thresholding and contour detection
- Outer boundaries and internal holes
- Contour-to-polyline drawing generation
- CAD-friendly 2D output workflows

**Technologies:** Python, OpenCV, FastAPI, DXF

> **Important:** This is an experimental 2D reconstruction workflow, not a complete or guaranteed-accurate 3D reconstruction system. Verify dimensions before manufacturing.

[Explore the project →](https://github.com/ahmedsajjad130107-a11y/cad-ai)
